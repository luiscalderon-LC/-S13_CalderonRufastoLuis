# 🏨 Hotel Costa 21 – Dashboard Angular

## Descripción del proyecto

Este proyecto fue desarrollado como parte de la actividad **S13 | AP7 – Dashboard con Angular Routing**.

Desarrollé un sistema de gestión hotelera llamado **Hotel Costa 21**, que permite consultar información de habitaciones, huéspedes y reservas. Utilicé Angular para crear las diferentes vistas y configurar un menú de navegación funcional.

## Tecnologías utilizadas

- Angular y TypeScript.
- HTML y CSS.
- Angular Router.
- Visual Studio Code.
- Git y GitHub.

## Funcionalidades

- **Inicio:** Muestra el resumen general del hotel, indicadores y últimas reservas.
- **Habitaciones:** Permite consultar habitaciones, precios, disponibilidad y realizar búsquedas.
- **Huéspedes:** Muestra los huéspedes registrados y permite buscarlos por sus datos.
- **Reservas:** Presenta las reservas, fechas de estadía y filtros por estado.

## Rutas del sistema

| Ruta | Descripción |
|---|---|
| `/inicio` | Panel principal |
| `/habitaciones` | Habitaciones del hotel |
| `/huespedes` | Directorio de huéspedes |
| `/reservas` | Listado de reservas |

## Ejecución del proyecto

**1. Clonar el repositorio:**

```bash
git clone https://github.com/luiscalderon-LC/-S13_CalderonRufastoLuis.git
```

**2. Ingresar al proyecto:**

```bash
cd -- -S13_CalderonRufastoLuis
```

**3. Instalar las dependencias:**

```bash
npm install
```

**4. Ejecutar el proyecto:**

```bash
npm start
```

**5. Abrir en el navegador:**

http://localhost:4200

## Nota

El sistema utiliza datos simulados para fines académicos. No requiere backend ni base de datos.

## Conclusión

Con esta actividad aprendí a utilizar Angular Routing para navegar entre diferentes secciones de una aplicación web. También practiqué la creación de componentes, el uso de datos simulados y la aplicación de estilos CSS para desarrollar un Dashboard sencillo y organizado.
